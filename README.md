### what I've shipped

**The Best Açaí — Customer Feedback System**

Production web app I built solo for a franchise chain. Customers scan a QR code at the store and rate their experience — no login, no friction. Each franchise location gets its own unique URL parameter (`?cidade=store-name`) and the data flows straight into Firebase Firestore.

Things I had to figure out: keeping animations GPU-only so it wouldn't lag on the tablets at the store, managing modal state without losing internal slide position during close animations, separating CSS by component when the original single file hit 1200+ lines.

> `React` · `Vite` · `Tailwind CSS` · `Firebase Firestore` · `CSS Modules`
